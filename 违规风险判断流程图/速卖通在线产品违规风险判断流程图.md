## 2. 规则索引加载

```mermaid
flowchart TB
    INIT["rebuild_index()<br/>启动时调用"] --> SCAN["glob 扫描 Clippings/*.md<br/>排除 __ 开头的文件"]
    SCAN --> LOOP["逐个文件 _parse_file()"]

    LOOP --> YAML["去掉 YAML frontmatter"]
    YAML --> TITLE["提取标题: ## 或 # 行"]
    YAML --> DATE["提取修订日期<br/>最新版本修订日期：..."]
    YAML --> CLAUSE["正则提取条款<br/>第X条 / 第X章 / 第X节<br/>或 1. / 2.1 等编号"]

    CLAUSE --> SPLIT["按条款边界切分文本段"]
    SPLIT --> PENALTY["在每段中搜索处罚关键词<br/>处罚 / 扣分 / 关闭 / 冻结<br/>删除 / 警告 / 屏蔽"]

    TITLE --> STORE
    DATE --> STORE
    CLAUSE --> STORE
    PENALTY --> STORE["存入 rules dict<br/>filename → {file, clauses,<br/>penalties, summary, wiki_link}"]

    STORE --> API["对外 API:<br/>get_rule(filename)<br/>get_clause_ref(file, clause)<br/>search_clauses(keyword)<br/>list_all()"]
```

## 8. 输出层

```mermaid
flowchart TB
    IN["all_results[行号] = [检测结果]"] --> EVAL["RiskEvaluator 逐行聚合"]

    EVAL --> LEVEL["get_overall_risk()"]
    LEVEL --> H["有任一'高' → 🔴 高风险有其他违规风险"]
    LEVEL --> M["仅'中'无'高' → 🟡 中风险只警告不扣分"]
    LEVEL --> L["仅'低' → 🟢 低风险无违规风险"]

    EVAL --> FMT["格式化输出"]
    FMT --> FH["高风险原因/补救措施"]
    FMT --> FM["中风险原因/补救措施"]
    FMT --> FHTML["reasons_html (前端弹窗)"]

    LEVEL --> WRITER["OutputWriter.add_columns()"]
    FH --> WRITER
    FM --> WRITER

    WRITER --> DF["DataFrame 新增5列:<br/>风险评级 | 高风险原因<br/>高风险补救措施<br/>中风险原因 | 中风险补救措施"]

    DF --> SAVE["write_excel() → openpyxl"]
    SAVE --> STYLE["颜色标记:<br/>🔴红底红字 / 🟡黄底棕字 / 🟢绿底绿字<br/>原因列 wrap_text + 列宽60"]

    STYLE --> FILE["保存文件"]
    FILE --> WEB["Web: uploads/risk_analysis_result_时间戳.xlsx"]
    FILE --> BATCH["Batch: output/原文件名_风险分析.xlsx"]

    EVAL --> STATS["get_stats()"]
    STATS --> STATS_OUT["{total, high, medium, low,<br/>category_counts} → 前端统计卡片"]
```
