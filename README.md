# 速卖通在线产品违规风险评级

> **AliExpress Online Product Violation Risk Analyzer**

基于 **Flask + 千问大模型（Qwen `qwen3.6-flash`）** 的速卖通在售产品违规风险自动化检测工具。导入「店小秘」导出的产品 Excel，系统即对每一款产品进行 **8 个维度** 的违规检测，输出**风险评级、违规原因与补救措施**，帮助运营团队在上架前规避封店 / 扣分 / 降权风险。

## 8 大检测维度

| 维度 | 检测器 | 检测内容 | 风险 |
|------|--------|----------|------|
| **A 违禁关键词** | `text_prohibited` | 毒品、武器弹药、管制刀具、烟草、酒精、赌博、色情低俗、虚拟货币、假币伪造、暴力歧视等 **10 大类**违禁词（正则 + AI 消歧） | 🔴 高 |
| **B 联系方式泄露** | `text_contact_leak` | 微信 / WhatsApp / QQ / 邮箱 / Skype / Facebook / Instagram / Telegram / 手机号等，**可见文本与 CSS 隐藏文本**均检测 | 🟡 中 |
| **C HTML 结构分析** | `html_structure` | `display:none` 等隐藏元素、外部引流链接、描述表格与系统属性不一致、隐藏关键词堆砌 | 🔴 高 / 🟡 中 |
| **D 品牌侵权** | `brand_check` | 内置约 150 个知名品牌库，AI 判定是侵权还是兼容配件；`SAFE_BRANDS` 合作品牌白名单过滤 | 🔴 高 |
| **E 搜索作弊** | `search_cheating` | 标题关键词堆砌、标题超长（>128 字符）、SKU 作弊（价差 >10 倍、超高价 / 超低价 / 零库存） | 🔴 高 / 🟡 中 |
| **F 图片内容分析** | `image_analysis` | 千问**视觉 AI** 识图：品牌 Logo、水印、联系方式、违禁内容；主图不足 3 张提醒 | 🔴 高 / 🟡 中 |
| **G 类目错放** | `category_mismatch` | 全类目树（5813 条）层级匹配 + AI 相关度打分，识别类目错放（★ 当前启用 **美容健康** L1 约束模式） | 🔴 高 / 🟡 中 |
| **H FDA 非法宣称** | `fda_claims` | 虚假 FDA 认证、医疗功效宣称（治癌 / 治糖尿病等）、非法医疗器械、夸张减肥 / 增高等 | 🔴 高 |

> 💡 **AI 双重验证机制**：大部分文本类检测器采用「正则扫描 → AI 二次判定」两阶段策略。例如 `wine` 出现在「酒柜 (wine fridge)」语境中属合法商品，AI 会将其判为非违规，避免误报。

## 风险评级体系

每个检测结果有独立的风险等级，最终汇总为整款产品的**综合评级**：

| 评级 | 含义 | 判定逻辑 |
|------|------|----------|
| 🔴 **高风险有其他违规风险** | 存在扣分 / 下架 / 处罚风险 | 任一检测项为「高」 |
| 🟡 **中风险只警告不扣分** | 存在警告风险，建议整改 | 无「高」，但存在「中」 |
| 🟢 **低风险无违规风险** | 基本合规 | 无「中」「高」 |

输出 Excel 在**原表基础上追加 5 列**：

1. **风险评级** — 综合评级（自动着色）
2. **高风险原因** — 逐条列出，附规则文件与条款引用
3. **高风险补救措施** — 对应的整改建议
4. **中风险原因** — 逐条列出
5. **中风险补救措施** — 对应的整改建议

## 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                         输入层 Input                         │
│   店小秘导出 Excel (.xlsx / .xls)   →   read_excel 解析       │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                       规则引擎 Rules                        │
│   Clippings/ 26 份速卖通官方规则 → rule_index 自动解析条款    │
│   （条款编号 / 处罚等级 / Wiki 链接）                          │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                     检测器层 Detectors                       │
│   A违禁词  B联系方式  C-HTML  D品牌                          │
│   E搜索作弊  F图片(视觉AI)  G类目  H-FDA                      │
│   每个检测器输出 {risk_level, category, reason, remedy,      │
│                  rule_ref}                                  │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                        AI 能力层 Qwen                        │
│   qwen3.6-flash：违规二次判定 / 品牌侵权判定 / 类目相关度打分  │
│   多模态视觉：产品图片品牌 / 水印 / 违禁内容识别               │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                        输出层 Output                         │
│   RiskEvaluator 聚合评级 → OutputWriter 写回 Excel           │
│   （风险评级 + 原因 + 补救措施，红/黄/绿着色）                 │
└─────────────────────────────────────────────────────────────┘
```

**数据流**：上传 Excel → 逐行读取 → 8 个检测器依次执行（`context` 上下文在检测器间传递，如 `image_analysis` 的结果会共享给品牌检测器使用）→ 单行聚合评级 → 全表导出。

## 快速开始

### 环境要求

- **Python 3.8+**（推荐 3.10+）
- 一个有效的 **千问 API Key**（阿里云百炼平台申请）

### 1. 安装依赖

```bash
pip install flask pandas openpyxl beautifulsoup4 lxml requests urllib3
```

### 2. 配置 API Key

编辑 [`config.py`](./config.py)，填入你的千问 Key：

```python
QWEN_API_KEY = "sk-your-qwen-api-key"   # ← 替换为你的 Key
```

> ⚠️ 仓库中为占位符 `sk-your-qwen-api-key`，请勿提交真实 Key。

### 3. Web 模式启动

```bash
python app.py
```

启动后浏览器访问 **http://localhost:5000**：

1. 上传店小秘导出的产品 Excel（≤ 50MB）
2. 选择需要启用的检测维度（默认 8 个全开）
3. 点击「开始分析」，等待逐行检测完成
4. 在结果页按风险等级筛选、查看详情，下载带评级的 Excel

### 4. 命令行批量模式

```bash
python app.py --batch
```

自动扫描 `input/` 目录下的所有 `.xlsx` / `.xls` 文件，逐个分析后输出到 `output/`。

也可以直接双击 **`批量分析.bat`**（开发环境）或 **`启动批量分析.bat`**（打包后）。

## Excel 输入 / 输出格式

### 输入（店小秘导出）

系统按列名智能读取，核心依赖以下列（其余列原样保留）：

| 列名 | 用途 |
|------|------|
| `店小秘产品ID` | 产品标识 |
| `产品名称` | 标题（违禁词 / 品牌 / 搜索作弊 / FDA 检测） |
| `产品简述` | 简述文本 |
| `产品详细描述1` / `产品详细描述2` | 富文本 / HTML 描述（结构解析） |
| `系统属性` / `自定义属性` | 属性文本（违禁词 / 联系方式 / 属性比对） |
| `产品图片` | 图片 URL，多个用 `;` 分隔（视觉 AI 分析） |
| `价格信息` | SKU 价格 JSON（SKU 作弊检测） |
| `产品类型` | 类目 ID（类目错放检测） |
| `所属店铺` / `产品分组` 等 | 展示信息 |

> 📌 **类目错放**（G 维度）额外要求存在 **`一级类目`** 或 **`一级目录`** 列（通常为最后一列）。当前仅启用 **美容健康** 一级类目的约束匹配。

### 输出

在原表末尾追加 5 列：`风险评级`、`高风险原因`、`高风险补救措施`、`中风险原因`、`中风险补救措施`，并带颜色标记（高=红、中=黄、低=绿）。

## PyInstaller 打包

项目内置打包配置，可在无 Python 环境的电脑上直接运行：

```bash
pip install pyinstaller
pyinstaller aliexpress_risk_analyzer.spec
```

- 生成 `dist/aliexpress_risk_analyzer.exe`
- 打包时自动包含 `templates/`、`static/`、`data/`、`Clippings/` 等资源
- 将 exe 与 `input/` 文件夹放同一目录，双击 `启动批量分析.bat` 即可批量处理

## 配置说明

核心配置集中在 [`config.py`](./config.py)，常用可调项：

| 配置 | 说明 | 默认 |
|------|------|------|
| `QWEN_API_KEY` | 千问 API Key（占位符，需自行填写） | `sk-your-qwen-api-key` |
| `QWEN_API_BASE_URL` | 阿里云百炼兼容端点 | Token Plan 团队版 |
| `QWEN_MODEL` | 千问模型 | `qwen3.6-flash` |
| `TITLE_LENGTH_MAX` | 标题长度上限（字符） | `128` |
| `TITLE_KEYWORD_REPEAT_MAX` | 关键词堆砌次数阈值 | `3` |
| `MIN_IMAGE_COUNT` | 最少主图数量 | `3` |
| `SKU_PRICE_RATIO_MAX` | SKU 价差比阈值 | `10` |
| `PROHIBITED_PATTERNS` | 10 大类违禁词正则 | — |
| `CONTACT_PATTERNS` | 12 类联系方式正则 | — |
| `HIDDEN_STYLE_PATTERNS` | CSS 隐藏样式正则 | — |
| `KNOWN_MAJOR_BRANDS` | 知名品牌库（约 150 个） | — |
| `SAFE_BRANDS` | 合作品牌白名单（不标记风险） | — |
| `FDA_ILLEGAL_PATTERNS` | FDA 非法宣称正则 | — |

> ⚠️ **白名单三处联动**：`SAFE_BRANDS` 同时用于标题品牌检测（`brand_check.py`）与图片品牌识别（`image_analysis.py`）。新增合作品牌时请同步确认三处过滤逻辑（白名单过滤、图片发现过滤）。

## 重要说明

1. **类目错放范围**：G 维度当前仅在「一级类目 = 美容健康」时启用 L1 约束匹配，其余一级类目不触发；如需扩展请修改 `category_mismatch.py`。
2. **AI 依赖**：品牌判定、违禁词消歧、图片分析、类目打分依赖千问 API。API 不可用时相关维度会降级为纯规则 / 关键词匹配并标注「非 AI 判断」。
3. **图片分析**：直接请求图片 URL 进行视觉识别，需保证目标图片可公网访问；系统内置 IPv4 优先修正以规避无 IPv6 网络下的超时。
4. **数据安全**：请勿将真实 API Key 提交到仓库。本项目不含任何用户数据。
5. **仅供参考**：检测结果基于平台公开规则与 AI 推断，不构成上架审核的最终结论，重大风险建议人工复核。
